**[Hands-on] Setting Up Google Antigravity, GitHub Desktop & the VMS Repositories**

**Overview:**Install the core tools, create two separate GitHub repositories, clone them locally, and establish the folder structure that will keep the Flutter frontend and Spring Boot backend independent from the beginning.

**Step 1: Install Google Antigravity**

• Open the Google Antigravity download page and install the IDE for your operating system.

• Launch Antigravity and sign in with the Google account you will use for the course.

![image](https://img-c.udemycdn.com/redactor/raw/article_lecture/2026-09-28_11-12-31-f1de8caf3919df94d575af5be5ee74de.png)

• Open the IDE once and keep the default settings unless your course environment requires a different configuration.

**Step 2: Install GitHub Desktop**

• Install GitHub Desktop for your operating system.

• Sign in with the same GitHub account you will use for the VMS repositories.

• Confirm that GitHub Desktop can see your account and local repositories.

**Step 3: Create the Two VMS Repositories**

• Create a frontend repository named vms-frontend.

• Create a backend repository named vms-backend.

• Keep both repositories separate. Do not place the Spring Boot project inside the Flutter repository or vice versa.

• Initialize each repository with a README so the repositories are immediately visible on GitHub.

**Step 4: Clone & Open the Repositories**

• Clone vms-frontend using GitHub Desktop and open the folder in Antigravity.

• Clone vms-backend separately and keep it available as the second workspace/project.

• Confirm that GitHub Desktop shows the correct repository before making changes.
