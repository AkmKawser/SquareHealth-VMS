Before we ask AI to build the VMS screens, we need to define how the application should look and behave. Every screen should feel like part of the same product. The login page, vehicle list, and forms should use the same colors, typography, spacing, and components. A clear design guideline helps us keep the interface consistent as we build each feature. The structure should stay simple. On desktop, we will use a left-side navigation for the main pages and a clear workspace on the right. Each page should have its title at the top, with the main action easy to find. Forms, tables, and content should follow the same alignment and spacing. This is a business application, so clarity is more important than decoration. Our visual style should feel clean and professional. We will use light backgrounds with deep blue and corporate blue as the main application colors. Green will communicate active or successful states, while red should be reserved for delete actions and errors. Cards, forms, and tables should use white surfaces, clear text, and subtle borders. Color should always help the user understand the interface, not simply decorate it. These design rules will now become part of our instructions to AI. Instead of simply asking AI to make a screen look good, we will tell it how the navigation should work, which colors to use, how the content should be arranged, and how components should stay consistent. This gives us more predictable results. With the design direction defined, we are ready to build the actual VMS front-end.
