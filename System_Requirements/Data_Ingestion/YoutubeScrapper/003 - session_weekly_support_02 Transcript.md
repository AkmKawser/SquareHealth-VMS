# Session Weekly Support 02: Full-Stack Web Development with Flutter & Spring Boot

**00:00:08 - Speaker 1:** আপু, আমি তাহলে স্ক্রিন শেয়ারটা করি নাকি? 

**00:03:01 - Speaker 1:** আচ্ছা, কী অবস্থা সবার? লাস্ট দিন আপনাদের যে ক্লাসটা ছিল, ওইখানে ছিল আসলে Spring Boot দিয়ে কীভাবে আপনারা REST API ডেভেলপ করতে পারেন ভাইব কোড করে—তার ওপর একটা ক্লাস হয়েছিল, একটা ধারণা দেওয়া হয়েছিল। তো হয়তো পুরোপুরি দেখানো হয়নি যে আমাদের অ্যাসাইনমেন্টের জন্য যে রিকোয়ারমেন্টটা, মানে যে যে API রিকোয়ারমেন্টটা দরকার, সবগুলো হয়তো ওইভাবে ডেভেলপ করে দেখানো হয়নি। তো ইনিশিয়ালি আমাদের তো আসলে দুইটা অ্যাসাইনমেন্ট: একটা ফার্স্ট অ্যাসাইনমেন্ট, একটা সেকেন্ড অ্যাসাইনমেন্ট—অ্যাসাইনমেন্ট ওয়ান আর অ্যাসাইনমেন্ট টু। তো অ্যাসাইনমেন্ট ওয়ানটা আমি একটু কিছু দেখায় দিবো। কারণ এখানে অনেকে আছেন যে অলরেডি কাজ করতেছেন ইন্ডাস্ট্রিতে, ফ্লাটারে কাজ করেন বা ব্যাকএন্ডে কাজ করেন। আবার কিছু আছেন ফ্রেশার যারা বা জুনিয়র, যারা আসলে কোনো আইডিয়া নেই আসলে ফ্লাটার কী জিনিস বা ফ্লাটার দিয়ে কীভাবে অ্যাপ বা প্রজেক্ট করে, বা ব্যাকএন্ডে কীভাবে API করে বা ব্যাকএন্ড সার্ভিস বানায়। তো এজন্য আরকি আমি চাইছিলাম যে ইনিশিয়ালি একটা কিছু দেখায় দিতে, মানে একটা পর্যায়ে নিয়ে যেতে, যেন পরবর্তীতে আপনাদের আরকি ওটা এক্সটেন্ড করতে বা আগায় যেতে হেল্প করে।

তো আমি হচ্ছে নিজেই ব্যাকএন্ডের যে API গুলো দরকার আমাদের—সিম্পলি কয়েকটা API যেমন: ভেহিকেল... আমরা তো আসলে VMS (Vehicle Management System) একটা প্রজেক্টে কাজ করতেছি, তো ভেহিকেল লিস্ট শো করার জন্য, ভেহিকেলের ডিটেইলস, তারপর হচ্ছে আপনার নতুন ভেহিকেল অ্যাড করা, ভেহিকেল ডিলিট করা বা কোনো ভেহিকেলের ইনফরমেশন আপডেট করা—এর জন্য আমি কয়েকটা API তৈরি করেছিলাম। তো ওইটা আমি আসলে ভাইব কোড করেই তৈরি করছি আমাদের। যে API-এর যে এন্ডপয়েন্টগুলো, এই যে: ভেহিকেল লিস্টটা ফেচ করে (এটা অবশ্য পেজিনেটেড ডেটা আরকি—মানে ধরেন আপনার কাছে ৫০০টা ভেহিকেলের লিস্ট আছে, তো এখানে ও ৫০০টা একবারেই দিবে না, পেজিং আকারে দিবে আরকি, ১০টা ১০টা করে আপনার একবারে করে দিবে আরকি)। তারপর হচ্ছে সিঙ্গেল ভেহিকেলের ডিটেইলসটা ফেচ করার জন্য এরকম, তারপর হচ্ছে আপনার নতুন ভেহিকেল অ্যাড করা বা ক্রিয়েট করা, ভেহিকেল আপডেট করার জন্য API আর ভেহিকেল ডিলিট করার জন্য API। তো আমি জাস্ট ভাইব কোড করে কিছু একটা, মানে মোটামুটি কাজ করার জন্য একটা এন্ডপয়েন্টগুলো তৈরি করে নিয়েছি। কারণ আজকে তো আমরা দেখবো ফ্রন্টএন্ডটা—মানে ফ্লাটার দিয়ে ফ্রন্টএন্ডে আমরা এই ব্যাকএন্ডের REST API-টা কীভাবে ইমপ্লিমেন্ট করতে পারি এবং আমাদের যে বেসিক একটা UI দাঁড় করাতে পারি আরকি। 

তো আমার ব্যাকএন্ড সার্ভিসটা আমি রান করে রাখি, কারণ এটা আমাদের লাগবে। এটা হচ্ছে IntelliJ IDEA। আমার ব্যাকএন্ড সার্ভিসটা রান হয়ে গেছে। এখন এটাকে আমি মিনিমাইজ করে আমাদের ফ্লাটার প্রজেক্টে চলে যাই। এটা হচ্ছে আমাদের ফ্লাটার প্রজেক্ট। ফার্স্ট যে আমাদের ওরিয়েন্টেশন ক্লাসটা ছিল বা ইন্ট্রোডাকশন ক্লাসটা ছিল, সেখানে আমি জাস্ট ফ্লাটারে একটা 'হ্যালো ওয়ার্ল্ড' টাইপের প্রজেক্ট ক্রিয়েট করে দেখিয়েছিলাম। তো এখানে আমি প্রজেক্টটা রান করি আরকি। এখানে আমি রান থেকে 'Run without debugging' দিই। 

এই যে জাস্ট আমাদের এই প্রজেক্টটা ছিল আরকি। জাস্ট ফ্লাটারে নতুন প্রজেক্ট ক্রিয়েট করলে যেমন হয় আরকি ডেমো প্রজেক্ট, জাস্ট এইটুকু ছিল। তো এখন আমি এটাকে প্রম্পট দিয়ে... এখানে যে এক্সিস্টিং প্রম্পটগুলো দেখতেছেন, জাস্ট দুইটা প্রম্পট দেওয়া আরকি আমাদের প্রজেক্ট ক্রিয়েট করার জন্য আরকি আমি করেছিলাম। এখন আমি একটা প্রম্পট দিবো। এটা হচ্ছে প্রম্পট। মোটামুটি আমি এক প্রম্পটে সবকিছু কাভার করার ট্রাই করছি, বাট বেটার হয় হচ্ছে ফিচার বাই ফিচার আলাদা আলাদা প্রম্পট ইউজ করা। তাহলে আরকি হ্যালুসিনেট করা বা হচ্ছে কনটেক্সট থেকে বের হয়ে যাওয়ার যে চান্সটা থাকে এজেন্টের, এটা একটু কমে আরকি। আমি মডেল চুজ করে নিচ্ছি। আপনারা যেকোনো একটা ইউজ করতে পারেন, ফ্ল্যাশও খারাপ না। আমি Gemini-এর যে লেটেস্ট মডেলটা আসছে এটা ইউজ করতেছি।

এখানে প্রম্পটটা একটু দেখি হালকা ওভারভিউ। আমরা কী কী প্যাকেজ ইউজ করবো সেটা আমি মেনশন করে দিছি। এখানে আমি জাস্ট প্রজেক্টের একটা ওভারভিউ দিছি যে আমাদের একটা ফ্রন্টএন্ড 'স্ট্যাক গ্রুপ'-এর ভেহিকেল ম্যানেজমেন্ট সিস্টেম বানাবো। API এন্ডপয়েন্টগুলো কী কী থাকবে—API-টা আমাদের ভেহিকেল লিস্ট ফেচ করার জন্য, ভেহিকেল ডিটেইলস দেখার জন্য, নতুন ভেহিকেল অ্যাড করার জন্য, ভেহিকেল আপডেট করার জন্য, ডিলিট করার জন্য। আমি যে ব্যাকএন্ড প্রজেক্টটা ক্রিয়েট করেছি, ব্যাকএন্ড প্রজেক্টের লোকেশনটা দিয়ে দিছি। তো এজেন্ট হচ্ছে ব্যাকএন্ড থেকে রিড করে আপনার প্রজেক্টটা আরকি অ্যানালাইসিস করে ওখানে API-গুলো কীভাবে আছে, ও কী কী রেসপন্স দিচ্ছে (কারণ এখানে আমি জাস্ট এন্ডপয়েন্টটা মেনশন করছি, কী কী রেসপন্স দিচ্ছে বা ক্রিয়েট করার সময় কী কী প্যারামিটার মানে বডিতে কী কী নেয় সেগুলো নাই)—তো ও এটা রিড করে ইজিলি হচ্ছে বুঝে নিতে পারবে আরকি। তারপর আমরা নেটওয়ার্ক কলিংয়ের জন্য কী কী কোন লাইব্রেরি ইউজ করবো, কীভাবে কী করবো—যেমন Retrofit ইউজ করবো। প্রজেক্ট স্ট্রাকচার—তার একটা বেসিক স্ট্রাকচার ফলো করতেছি আমরা। পেজিনেশন ইউজ করবো যে আমাদের যে ভেহিকেল লিস্টটা এটা আসলে পেজ বাই পেজ ডেটা লোড হবে, সবগুলো একসাথে না হয়ে। স্ক্রিনগুলো কী হবে, UI-গুলো কী হবে না হবে। আর লাস্টে হচ্ছে ও রান করে দেখবে, তারপর হচ্ছে টেস্ট কেস চালাবে আরকি—এগুলো আরকি। তারপর একটা README লিখবে প্রজেক্টের ওভারঅল একটা README লিখে দিবে। এটাই ছিল জাস্ট একটা বেসিক প্রম্পট। অলরেডি এজেন্ট কাজ করছে এখানে।
