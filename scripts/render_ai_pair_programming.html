The 6-Stage Pair Programming Lifecycle
Execution Loop
1
Context Grounding & Workspace Discovery

AI scans @workspace, indexes project dependencies, reads REQUIREMENTS.md, and aligns with Stark Group Design Guidelines.

@workspace Review requirements and inspect existing DTO contracts
2
Atomic Micro-Prompting

Engineer issues focused, single-responsibility prompts rather than monolithic instructions. Prevents hallucination and code sprawl.

Prompt: Implement VehicleService duplicate plate validation rule only
3
Synthesized Diff Inspection & Verification

Engineer verifies generated code against requirements. Ensures DTO isolation, correct status codes (HTTP 409 vs 201), and pure architecture.

4
Runtime Execution & Verification

Execute actual builds and tests in the workspace terminal: Mockito unit tests, MockMvc API tests, and browser smoke tests.

mvn test -Dtest=VehicleServiceTest; flutter test
5
Diagnostic Feedback & Self-Correction

When runtime errors or test failures occur, pipe exact stack traces back to Antigravity to isolate the issue and apply surgical fixes.

6
Attestation, Audit & Version Sync

Run scripts/audit_rendering.py, append complete session reasoning to chat.md, and push directly to origin/main.

Core Governance & Safety Rules
Invariants

🛡️ The "Never Blindly Accept" Principle

Every generated component must be executable, compile cleanly, and match the SRS source requirement cited in brackets.

🔒 Secret & Credential Boundary

Zero production passwords, JWT keys, or API tokens committed to version control. Uses environment variables and profiles.

📦 Decoupled Monorepo Isolation

Frontend (Dart) and Backend (Java) are decoupled into independent subprojects. No cross-stack leakage or build tool collision.

Verification & Testing Matrix
Quality Assurance

Level 1: Unit Isolation (Mockito)

Verify business rules (e.g. duplicate vehicle check) in pure isolation without live databases.

Level 2: API Contract Integration (MockMvc)

Verify HTTP status codes (200, 201, 400, 404, 409) and JSON serialization boundaries.

Level 3: End-to-End User Journey

Full interactive smoke test from login to vehicle creation and UI updates.
